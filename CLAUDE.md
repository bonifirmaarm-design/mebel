# VOLNA

Магазин мебели. Портфолио-проект. Сайт целиком — `docs/index.html`
(эта же папка публикуется через GitHub Pages, см. README).

## Правило: дизайн-скиллы обязательны

Перед любой работой над интерфейсом — новый блок, переверстка, правка стилей,
подбор шрифта, цвета или анимации — читать и применять скиллы из
`.claude/skills/`. Это не опция.

Минимальный набор на каждую задачу по UI:

| Скилл | Когда |
|---|---|
| `impeccable` | всегда; `reference/craft-floor.md` — перед любой правкой UI |
| `frontend-design` | направление, палитра, типографика |
| `hallmark` | проверка на AI-slop перед публикацией |
| `taste-skill`, `interface-design` | композиция и вкус |
| `scroll-craft` | скролл-анимации и герой |
| `web-design-guidelines` | ревизия доступности и разметки |
| `typography`, `web-typography`, `typography-scale` | шрифтовые решения |
| `critique-*`, `ux-heuristics`, `design-audit` | самокритика перед сдачей |

После правки UI прогонять механический детектор:

```
.claude/skills/impeccable/scripts/impeccable detect --json docs/index.html
```

## Что запрещено в этом проекте

Выжимка из `impeccable/reference/craft-floor.md` и `frontend-design`, нарушения
которой уже приходилось откатывать:

- Одинаковые скруглённые карточки «заголовок + текст» как структура страницы.
  Вложенные карточки — всегда ошибка.
- Надпись-ярлык (eyebrow) над заголовком.
- Нумерация блоков 01 / 02 / 03, если это не настоящая последовательность.
- Один и тот же радиус и одна и та же тень на всех элементах.
- Одинаковое появление «сдвиг вверх + прозрачность» на каждой секции.
  Один продуманный момент на страницу, остальное — в ответ на действие.
- Градиентный текст, стекло и блюр как украшение.
- Эмодзи вместо иконок.

Браузерные поверхности (выделение текста, каретка, скроллбар, кольцо фокуса)
красятся из палитры, а не остаются дефолтными.

## Контент

- Генерация картинок в Krea — **только по явной просьбе**. Токены платные.
- Исходники референсов лежат в `references/`, ассеты — в `docs/images/`.

## Типографика

- Заголовочная гарнитура — **Unbounded** (выбрана заказчиком). Задана один раз
  токеном `--display`, менять только через него.
- Текстовая — **Onest**.
- Капс разряжать на 5–12 %, не больше.

## Стек

Один HTML-файл без сборки: GSAP + ScrollTrigger с cdnjs, Lenis с jsdelivr,
шрифты с Google Fonts. Папка `docs/` самодостаточна и открывается как есть.
Дальше разворачивается в Next.js.
