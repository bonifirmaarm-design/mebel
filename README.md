# VOLNA

Прототип сайта мебельной мастерской. Портфолио-проект.

Готовый сайт лежит в папке **`docs/`**. Ни сборки, ни установки, ни сервера,
ни интернета — открыть `index.html` и всё работает.

```
docs/
  index.html      вёрстка, стили и скрипты в одном файле
  images/         10 фотографий
  fonts/          Unbounded и Onest, 8 файлов
  fonts.css       подключение шрифтов
  lib/            GSAP, ScrollTrigger, Lenis
  .nojekyll       отключает сборку Jekyll на GitHub Pages
```

## Как выложить

Сайт уже лежит в `main`. Осталось выбрать, где его показывать.

### GitHub Pages — бесплатно, прямо из этого репозитория

Settings → Pages → Source: **Deploy from a branch**, Branch: **main**,
папка: **/docs** → Save.

Через пару минут сайт будет на `https://bonifirmaarm-design.github.io/mebel/`.

Файл `.nojekyll` в `docs/` обязателен. Без него GitHub Pages прогоняет папку
через Jekyll: тот показывает README вместо `index.html` и вдобавок молча
выбрасывает папку с библиотеками, если назвать её `vendor`.

### Netlify или Vercel — если нужен свой домен

Перетащить папку `docs` на [app.netlify.com/drop](https://app.netlify.com/drop).
Ссылка появится сразу, домен подключается в настройках.

### Обычный хостинг

Залить содержимое `docs/` в корень сайта по FTP. `index.html` должен лежать
в корне, папки `images`, `fonts`, `lib` и файл `fonts.css` — рядом с ним.

## Интернет не нужен

Сайт полностью автономен: шрифты, GSAP, ScrollTrigger и Lenis лежат внутри
папки. Ни одной внешней ссылки — работает без сети, с флешки и на офлайн-показе.
Проверено в браузере с заблокированным HTTP: шрифты грузятся, анимации идут,
корзина и поиск работают.

Вес папки — около 1,5 МБ, из них 1,1 МБ фотографии.

## Что внутри

| Раздел | Что делает |
|---|---|
| Шапка | поиск, избранное, корзина; на телефоне — иконки и выдвижное меню |
| Герой | имя бренда во всю ширину, мебель стоит на базовой линии |
| Новая коллекция | четыре предмета, добавляются в корзину |
| Как это сделано | материалы и сроки |
| В интерьере | пять комнат |
| Каталог | список с фото, ценами и кнопками |
| Мастерская | адрес и контакты |

Корзина, избранное и поиск работают по-настоящему. Содержимое корзины
переживает перезагрузку страницы.

## Разработка

Править `docs/index.html` напрямую — он же и есть сайт. Правила проекта,
обязательные дизайн-скиллы и список запрещённых приёмов — в `CLAUDE.md`.

После правки интерфейса прогнать детектор:

```
.claude/skills/impeccable/scripts/impeccable detect --json docs/index.html
```
